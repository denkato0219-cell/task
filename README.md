# きょうのよてい

障害のある子どもの一日を、絵とタイマーと声で見せるスケジュールアプリです。iPhoneのホーム画面に追加して使います。

- **今・次・今日の流れ**を大きく表示。残り時間は赤い円のタイマーで見せます
- 声かけ：「あと5ふんごに〜をはじめるよ」「いまから〜をはじめるよ」「あと5ふんでおわりだよ」「〜おわりだよ」（ことばはこどもごとに変更可）
- 「できた！」で はなまる
- 学校の日・お休みの日などの**予定パターン**を曜日で使い分け
- 予定が延びたら「＋5分／＋10分／＋15分」で、あとの予定も今日だけ後ろへ
- 文字は「ひらがな／漢字＋ふりがな／漢字」から選択
- 支援員が作ったこどもの予定を、**コード**で家庭のiPhoneと共有
- **アプリを閉じていても通知**（通知サーバーを使う場合）

| | アプリを開いている | 閉じている・ロック中 |
|---|---|---|
| 画面の表示 | ◯ | ◯ 通知（文字） |
| 音 | ◯ チャイム | ◯ iPhoneの通知音（マナーモードでは鳴りません） |
| 声 | ◯ | ✕ 通知をタップしてアプリを開くと読み上げます |

## 支援員さん向け：はじめの準備（1回だけ）

### 1. アプリを公開する（GitHub Pages）
1. このリポジトリの **Settings → Pages** を開く
2. 「Build and deployment」の Source を **Deploy from a branch**、Branch を **main / (root)** にして Save
3. 数分後、`https://denkato0219-cell.github.io/task/` で開けます

### 2. Cloudflare のアカウントを作る（無料）
1. https://dash.cloudflare.com/sign-up で登録
2. 左のメニュー **Workers & Pages** を一度開く（初回に `xxxx.workers.dev` のサブドメイン名を決める画面が出たら、好きな名前で登録）
3. 画面右側などに出ている **Account ID** をメモ（Workers & Pages の画面、または アカウントのホームにあります）

### 3. Cloudflare の APIトークンを作る
1. 右上のアカウント → **My Profile → API Tokens → Create Token**
2. **Edit Cloudflare Workers** のテンプレートを選ぶ
3. Permissions に1行追加：**Account ／ D1 ／ Edit**
4. Account Resources を自分のアカウントにして、トークンを作成し、表示された文字列をコピー

### 4. GitHub に鍵を登録する
このリポジトリの **Settings → Secrets and variables → Actions → New repository secret** で、次の3つを登録します。

| 名前 | 中身 |
|---|---|
| `CLOUDFLARE_API_TOKEN` | 3 で作ったトークン |
| `CLOUDFLARE_ACCOUNT_ID` | 2 でメモした Account ID |
| `ORG_KEY` | **事業所キー**。支援員だけが知る合言葉（20文字以上の長い文字列がおすすめ） |

### 5. 通知サーバーを立ち上げる
1. **Actions** タブ → **Deploy notification server** → **Run workflow**
2. 緑のチェックが付けば完了です。サーバーのアドレスは自動で `config.js` に保存され、アプリに反映されます（数分かかります）

## 支援員さん：こどもを登録して家庭にわたす

1. iPhoneのSafariでアプリを開き、**共有ボタン → ホーム画面に追加**
2. ホーム画面のアイコンから開き、「おとなの設定」
3. こどものよびかた・予定パターン・声かけのことばを設定
4. 「アプリを とじていても しらせる」で **事業所キー** を入れて「とうろくして コードを つくる」
5. 表示された **コード（例：ABCDE-23456）** をご家庭に伝える
6. もう一人登録するときは「＋ こどもを ふやす」（1台に10人まで）

## ご家庭：はじめかた

1. 支援員さんから聞いたURLをiPhoneの **Safari** で開く
2. **共有ボタン → ホーム画面に追加**
3. ホーム画面の「きょうのよてい」アイコンから開く（※Safariのままでは通知が届きません）
4. 「おとなの設定」→「コードを もらった かた」にコードを入れて「よみこむ」
5. 「この iPhoneで つうちを うける」→ 通知を **許可**
6. 「テスト つうち」で届くか確認
7. こどもの画面にもどり「はじめる」を押すと、開いている間は声でも知らせます

### うまく届かないとき
- iPhoneの **設定 → 通知 → きょうのよてい** がオンか
- **集中モード・おやすみモード** になっていないか
- マナーモード（消音スイッチ）だと音は鳴りません（画面には出ます）
- アプリを削除して入れ直したときは、もう一度「つうちを うける」を押す

## 開発者向け
```
index.html       アプリ本体（1ファイル）
sw.js            オフライン用キャッシュと、通知の表示
config.js        通知サーバーのアドレス（Actions が自動で書き込み）
server/          通知サーバー（Cloudflare Worker + D1）
  src/index.js     API と 1分ごとの通知
  src/schedule.js  その分に送るメッセージの計算（index.html と同じルール）
  src/push.js      Web Push の暗号化と送信（ライブラリなし）
  test/            npm test で実行
```
